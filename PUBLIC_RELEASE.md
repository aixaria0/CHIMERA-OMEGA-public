# Public release boundary

This repository is a fresh, source-only public snapshot of CHIMERA OMEGA's bounded verifier kernel. It intentionally does not publish the private development repository's Git history, branches, pull requests, workflow logs, integration credentials, or internal cross-project operational metadata.

This public snapshot is **not** an independently validated production system. The kernel checks bounded claim/evidence relations under explicitly supplied assumptions; structural validity and signatures do not imply external truth, independent observation, production reachability, or consensus finality.
